# vnmac_elearning Frontend

React + TypeScript + Vite frontend for the `vnmac_elearning` platform.

## Project path

- `frontend/vnmac_elearning.web`

## Stack

- React
- TypeScript
- Vite
- React Router
- TanStack Query

## Run

```bash
npm install
npm run dev
```

The Vite dev server proxies `/api` requests to the backend at `http://localhost:5211`.

## Build

```bash
npm run build
```

## Main frontend areas

- Learner login
- Learner dashboard
- Course and lesson player
- Interactive and quiz question engine
- SCORM player wrapper page
- Certificate page and verification page
- Admin CMS for courses, lessons, questions, users, and analytics
